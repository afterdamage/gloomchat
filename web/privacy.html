Matrix

GloomChat uses the Matrix protocol. GloomChat is a client that can connect to compatible Matrix servers. The data protection terms of the selected server apply.

For convenience, one or more servers may be set as defaults. GloomChat developers do not guarantee the trustworthiness of any server. Before first communication, users are informed which server is used.

GloomChat communicates with the selected server and with OpenStreetMap for map display.

More information: matrix.org

Database

GloomChat caches some server data locally. On mobile and desktop this uses sqflite. On web, IndexedDB is used. GloomChat attempts to encrypt local data with SQLCipher and stores encryption keys in secure storage when supported.

More information:

  • sqflite
  • sqlcipher_flutter_libs

Encryption

All communication between GloomChat and servers uses transport encryption.

GloomChat also supports end-to-end encryption using Vodozemac and enables it by default for private chats.

More information: Vodozemac

App Permissions

Permissions on Android and iOS are similar, but exact names can differ.

Internet Access

Required to communicate with Matrix servers.

Notifications

Used for local and push notifications about new messages, calls, and other app activity.

Vibrate

Used for local notifications.

Camera

Used for camera-based features such as taking photos or scanning QR codes when the user chooses to do so.

Record Audio

Required to send voice messages and participate in calls.

Write External Storage

Required to save received files.

Read External Storage

Required to send files from local storage.

Location

Used only when a user chooses to share current location in chat.

Bluetooth

Used for audio accessories such as headsets or other connected devices during calls or voice use.

Modify Audio Settings

Used to adjust audio routing and audio behavior during voice and call features.

Wake Lock

Used to keep the device awake during calls, voice messages, or other active foreground tasks.

Foreground Service

Used for ongoing features such as calls, microphone use, camera use, or screen sharing when the user starts those features.

Push Notifications

On Android and iOS, GloomChat uses Firebase Cloud Messaging (FCM) for push delivery:

  1. The Matrix server sends a push payload to the push gateway.
  2. The gateway forwards it to FCM.
  3. FCM queues delivery until the device is reachable.
  4. The device receives and displays the notification.

Gateway reference: matrix-org/sygnal

GloomChat uses the event_id_only push format.

Google Play Safety Standards

GloomChat is committed to helping maintain a safe and respectful environment. As a Matrix client, GloomChat connects users to Matrix servers, but does not directly host those servers.

Users can report harmful content or users to server administrators from inside the app by using report actions on messages and profiles.

Moderation reference: Matrix moderation docs
